ご提示いただいた画像は、RPGのステータス画面のようで、選手にとって非常にモチベーションが上がる素晴らしいUIですね！

この「積み上げ式（経験値方式）」の達成率計算と、それをグラフに反映させるためのReplit用プロンプトを作成しました。

---

### Replit用プロンプト（達成率計算ロジックと入団日管理の実装）

```text
あなたはデータ分析と可視化に強いフルスタックエンジニアです。
現在開発中のシステムにおいて、選手の評価データを分析し、添付画像のような「累積達成率（Achievement Rate）」を表示する機能を実装してください。

## 1. 要件定義

### A. 達成率の計算ロジック (重要)
単なる平均点ではなく、**「入団してから現在までに積み上げた経験値」**として計算します。
- **分子:** 入団日以降に行われた全評価の「獲得点数」の合計。
- **分母:** 入団日以降に行われた全評価の「満点（MAX点数）」の合計。
- **計算式:** `(獲得点数の合計 / 満点の合計) * 100`

### B. 必要なデータ項目
- 計算の開始地点を特定するため、選手データに**「入団日 (Join Date)」**が必要です。

### C. 可視化要件
1. **ステータス表:**
   - カテゴリ（心・技・体・戦術など）ごとの「MAX累積」「現在値累積」「達成率」を表形式で表示。
   - 達成率に応じて背景色を変える（例: 0-30%は赤、30-60%はオレンジ、60%以上は青など）。
2. **推移グラフ:**
   - 既存の上達グラフを改修し、Y軸を「点数」ではなく「その時点での累積達成率(%)」に変更する。

## 2. 依頼内容

### Step 1: schema.prisma の拡張
`User` モデルにフィールドを追加してください。

```prisma
model User {
  // ...既存フィールド
  joinDate      DateTime? @default(now()) // 入団日
  // ...
}

```

### Step 2: データ登録・編集UIの修正

* **新規登録時:** 選手登録フォームに「入団日（年月）」入力欄を追加。
* **設定画面:** チーム管理者が後から選手の「入団日」を修正できるようにしてください。

### Step 3: 計算ロジックの実装 (Server Actions / Utils)

`lib/analytics.ts` などに、以下の計算を行う関数 `calculateCumulativeStats(playerId)` を作成してください。

1. 対象選手の `joinDate` を取得（未設定なら作成日を使用）。
2. `joinDate` 以降の全 `EvaluationRecord` を取得。
3. カテゴリ（ParentCategory）ごとに、以下を集計：
* `totalMaxScore`: (各項目の満点 × 評価回数) の合計
* `totalActualScore`: (実際に獲得した点数) の合計
* `rate`: パーセンテージ


4. グラフ用データとして、月ごとの「その月末時点での累積達成率」の配列を生成して返す。

### Step 4: UI実装 (ダッシュボード)

画像のデザインを再現した `AchievementTable` コンポーネントを作成してください。

* **カラム:** カテゴリ名 / 体得数MAX / 現在値 / 達成率
* **デザイン:** Tailwind CSSを使用し、達成率のセルは数値によって色 (`bg-red-500`, `bg-orange-400` 等) を動的に変更してください。

### Step 5: グラフコンポーネントの改修

既存の `ProgressChart` を修正し、Step 3で生成した「月次累積達成率」を表示するように変更してください。

* Y軸: 0% 〜 100%
* X軸: 入団日 〜 現在の月

## 技術スタック

* Next.js, Prisma, Recharts (グラフ描画), date-fns

```

***

### 💡 実装のポイント（Replitへの補足）

このプロンプトを実行した後、Replitが**「カテゴリごとの満点（MAX）」をどこから持ってくるか**迷う可能性があります。

もし評価項目マスタ（`EvaluationItem` など）に `maxScore` というフィールドがまだ無い場合は、以下のように追加指示を出してください。

> 「ちなみに、各評価項目の満点（分母）は、`EvaluationItem` テーブルの `maxScore` カラム（無ければ追加、デフォルト5点など）を参照して計算してください」

```

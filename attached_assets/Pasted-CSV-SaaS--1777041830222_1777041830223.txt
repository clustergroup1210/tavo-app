CSVで一括登録したチームを「仮登録（空箱）」として扱い、チームの代表者がアクションを起こすことで「本登録（アクティブ）」になり、初めて選手が登録できるようになる仕組みですね。

これはSaaS（サービス提供型システム）における**「オンボーディング（利用開始）フロー」の超・王道パターン**です！非常に理にかなった設計だと思います。

これをReplitに実装させるためのプロンプトを作成しました。仕組みとしては、**「運営が仮登録チームの『招待リンク』を発行し、チーム代表者がそのリンクから自分のアカウントを作ると、チームが『本登録』に切り替わる」**という流れで指示を出しています。

### Replit用プロンプト（チームの仮登録・本登録フローの実装）

```text
あなたはSaaSのアーキテクチャ設計に強いフルスタックエンジニアです。
現在開発中のシステムにおいて、運営がCSV等で登録したチームを「仮登録」とし、チーム代表者の手続きを経て「本登録」に移行するフローを実装してください。本登録が完了するまで、選手データの登録はできない仕様とします。

## 1. 要件定義

### A. チームの状態管理
チーム（Team）モデルに「状態（Status）」を持たせます。
- `PENDING` (仮登録): 運営がシステムに枠だけを作った状態。
- `ACTIVE` (本登録): チーム代表者が招待を受け、初期設定を完了した状態。

### B. 本登録（アクティベーション）フロー
1. 運営（SUPER_ADMIN）が、仮登録チームごとの「招待リンク（一意のトークン付きURL）」を発行・取得できる。
2. チーム代表者がそのリンクにアクセスし、管理者アカウント（名前、パスワード等）を作成する。
3. 作成完了と同時に、紐づくチームのステータスが `ACTIVE` に変わり、代表者はそのチームの `ADMIN` 権限を持つユーザーとして登録される。

### C. 機能制限（ガード）
- チームステータスが `ACTIVE` でない場合、そのチームに対する選手（Player）の新規登録や評価データの作成をブロックする。

## 2. 依頼内容

### Step 1: schema.prisma の拡張
`Team` モデルにステータスを追加し、招待用のモデルを作成してください。

```prisma
// Teamモデルの拡張
model Team {
  // ...既存フィールド
  status      String   @default("PENDING") // PENDING or ACTIVE
  // ...
}

// 招待リンク管理用モデル
model TeamInvitation {
  id        String   @id @default(cuid())
  teamId    String   @unique
  token     String   @unique // ランダムな文字列
  expiresAt DateTime
  createdAt DateTime @default(now())

  team      Team     @relation(fields: [teamId], references: [id])
}
```

### Step 2: 招待リンク発行機能 (SUPER_ADMIN向け)
- 運営側のチーム一覧画面（またはチーム詳細画面）に、「招待リンクを発行/コピーする」ボタンを作成してください。
- 裏側の Server Action で `TeamInvitation` レコードを生成（有効期限は7日間など）し、`/invite/[token]` のようなURLをフロントに返してください。

### Step 3: 本登録画面の実装 (チーム代表者向け)
- ルーティング `app/invite/[token]/page.tsx` を作成してください。
- トークンを検証し、有効であれば「〇〇チームの管理者アカウント作成」フォームを表示します。
- フォーム送信時の Server Action で以下をトランザクション（一括処理）で実行してください。
  1. `User`（権限: TEAM_ADMIN）の作成。
  2. `Team` の `status` を `ACTIVE` に更新。
  3. 使用済みの `TeamInvitation` を削除。

### Step 4: 選手登録のガード処理
- 選手を追加する Server Action（例: `createPlayer` 等）の冒頭で、対象チームの `status` が `ACTIVE` であるかチェックするロジックを追加してください。`PENDING` の場合はエラーを返してください。

## 技術スタック
- Next.js (App Router), Prisma, Tailwind CSS
```

### 💡 運用時のイメージ

この機能が実装されると、以下のような運用ができるようになります。

1. **運営:** 先ほど作ったCSVで「茨城県のチーム一覧」を一括でシステムに流し込む（この時点では全部「仮登録」）。
2. **運営:** システム上で「鹿島アントラーズJY」の招待リンクボタンをポチッと押してURLをコピー。
3. **運営:** 鹿島アントラーズJYの担当者へ、メールやLINEで「こちらのURLからアカウントを作って利用を開始してください：`https://.../invite/abcd123`」と連絡する。
4. **チーム担当者:** URLを開いて、自分の名前とパスワードを入れて登録。
5. **システム:** 自動で鹿島アントラーズJYを「本登録」に切り替え、選手登録機能などを解放する。

これで、運営側の入力の手間を省きつつ、セキュリティも保たれた綺麗な流れが作れます！
